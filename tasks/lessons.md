# Lessons

- Failure mode: a temporary symlink to another checkout's `node_modules` made TypeScript include that checkout's dependency declarations and Vite write its temporary config into a read-only dependency path. Detection: lint errors referenced `node_modules.shared-link`, and Vite failed to open `.vite-temp` with `EPERM`. Prevention: install dependencies into the isolated worktree from the local offline cache; keep any shared dependency symlink outside the repository tree.
- Failure mode: the generated Ford-web API contract was updated while the source snapshot `openapi.ford-service.yaml` remained stale, so the aggregate API contract test failed despite the generated files matching the live Service source. Detection: `api:check` passed against Service but `apiContract.test.ts` compared against the stale checked-in snapshot. Prevention: update the checked-in Service contract snapshot and regenerate all web contracts together, then run both contract checks and tests.
- Failure mode: Vitest runs with `isolate: false`, so different UI test files that mocked the same API module leaked incomplete mock exports into the new panel. Detection: full-suite tests failed by order while the focused panel suite passed. Prevention: keep independently owned API contracts in separate modules and rerun related tests together before the full suite.
